This is where the grid comes alive. Each example takes **one real decision** —
straight from the [Forge Dojo: Grid Clash](https://forge100.com) game scenarios —
and maps it onto the board, cell by cell.

The pattern is always the same, and it's the whole point of the model:

> **A single decision is never one cell.** It strengthens some cells (`+`),
> costs others (`−`), and the **trade-off between them is the lesson.**

Each cell impact carries three things:

- a **sign** — `+` strengthens the cell, `−` costs it;
- a **role** — `primary` (the main intended effect), `secondary` (a knock-on
  effect), or `tradeoff` (the price you pay);
- a **weight** (0–1) — how strong the effect is.

## How to read the diagrams

Each example includes a mini-grid where affected cells light up:

- 🟩 **green** = the decision **strengthens** that cell (`+`)
- 🟥 **red** = the decision **costs** that cell (`−`)
- grey = untouched

The badge in each lit cell shows the sign, and the role + weight sit along the
bottom. Trace the greens and reds across **domains** (columns) and you can see at
a glance whether a decision is, say, "great for Finance and Operations but paid
for out of People."
